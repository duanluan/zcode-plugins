# ADR-0007：文案标点用弯引号，不用直角引号

- 状态：已采纳（2026-10-16）
- 影响范围：全部插件的用户可见文案（页面 UI、README、术语表、ADR）与 zcode-pro（待落地）

## 背景

UI 与文档里曾混用直角引号「」（如“默认显示压缩时被省略的行……「完整输出」是压缩前的原始输出”）。直角引号在中文输入法里需要额外切换、视觉密度高，用户明确要求统一为弯引号。

## 决策

1. 引用界面元素、按钮名、字段名时一律用**弯引号**：`“完整输出”`、`“被省略的行”`；不使用直角引号 `「」『』`。
2. 代码/路径/命令仍用反引号（\`rtk recall\`）；强调用弯引号或加粗，不用直角引号。
3. 2026-10-16 已把本次新写文案里的 52 处直角引号全部替换为弯引号；今后新文案以本 ADR 为准。

## 后果

- 全部用户可见文本风格统一；搜索直角引号可发现违规残留。
- 存量历史文档（本次会话之前的内容）不主动清理，改动到哪行就顺手换到哪行。
