# ADR-0006：数字分组跟随界面语言——中文四位分组、大数用"亿"

- 状态：已采纳（2026-10-16）
- 影响范围：全部插件页面的数字显示（ui-common/zcode-page.ts 的 fmtInt / fmtBigTokens）；规则同样适用于 zcode-pro（待该仓库另行落地）

## 背景

数字按千进制三位加逗号（35,313,866）是英文习惯；中文的数位是四位变化（万、百万、千万、亿），三位分组对中文用户不可读。headroom 节省的 token 量级会到亿级，一长串数字没有信息量。

## 决策

1. **界面语言为中文**（宿主 locale 以 `zh` 开头，连接前以浏览器语言兜底）时，整数按**四位一组**加英文逗号：`3531,3866`；其他语言保持千进制三位分组（`en-US` 分组）。
2. **节省类大数**（token）：中文且 ≥ 1 亿时显示 `x.xxxx 亿`（四位小数、去尾零，如 `1.2345 亿`、`2 亿`）；1 亿以下与其他语言按第 1 条分组。实现在 `fmtBigTokens`，目前用于 headroom 面板的节省量显示位（卡片、每日明细、模型分布）。
3. **发给模型的内容不加分组**：updateModelContext 等机器可读文本里的数字保持 ASCII 原样，分组只作用于用户看到的 DOM。
4. 语言在连接时读取 `hostContext.locale`，宿主语言变化（onhostcontextchanged）时重新生效。

## 后果

- fmtInt 的行为随语言切换，中文用户看到 3531,3866，英文用户看到 35,313,866。
- 日期/百分比/美元金额不受影响（原本就不是千分位分组）。
- zcode-pro 后续落地同一规则时以本 ADR 为准。
