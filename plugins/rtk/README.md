# rtk：命令输出源头压缩

[← 返回插件总览](../../README.md#-插件一览)

**装后必做：`/rtk-setup`**。安装 rtk（官方脚本，网络中断自动改用 tar 包）→ 生成官方全局提示词 → 同步进 `~/.zcode/AGENTS.md` → 验证改写，一条命令完成。

**原理**：rtk（单个可执行文件，内置 100+ 命令过滤器）在命令输出**进入对话之前**压缩 60-90%，与 headroom（请求层）互补。"何时压缩、怎么压缩"完全由 rtk 官方机制决定，插件只负责安装与接线：

1. **官方全局提示词**：`rtk init -g` 生成的 `RTK.md` 同步进 `~/.zcode/AGENTS.md`（带 `<!-- rtk:start/end -->` 标记）；每次会话自动比对，rtk 升级后跟随更新
2. **官方改写判断**：每次运行 Bash 命令前调用 `rtk rewrite`（rtk 官方的改写判断）——有等价改写才拦一次，并直接给出改写后的命令，照做即可
3. **安全护栏**：输出重定向进文件（`>/dev/null` 除外）、命令替换 `$()`、已套 rtk、已管道限量（`| head`）的命令一律放行不改写；rtk 未装或 `/rtk off` 时完全静默

### 🚀 使用

```
/rtk-setup        # 装后必做：安装 rtk + 同步提示词 + 验证
/rtk-status       # 版本、改写提醒状态、提示词同步、节省统计
/rtk off          # 关闭改写提醒（手动 rtk <命令> 不受影响）
/rtk gain         # rtk 自身统计的节省明细
```

日常无需任何操作：正常跑命令，出现"[rtk] 改用以下等价命令"提示时照做即可。主动压缩就给命令加 `rtk ` 前缀（如 `rtk git status`）；被压缩的输出结果不可用时按提示 `rtk proxy <原命令>` 取原文。

**图形化设置页面在 [zcode-pro](https://github.com/duanluan/zcode-pro) 中**：用「ZCode Pro」启动 ZCode 后，右键侧边栏底部的设置按钮（齿轮）打开设置窗口，「rtk 压缩」页管理改写提醒、命令白名单，以及 rtk 本体的检查更新与一键升级。
